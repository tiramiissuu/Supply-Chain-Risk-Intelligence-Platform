# Supply Chain Risk Intelligence Platform

## Overview
Advanced SQL and Business Intelligence project that analyzes inventory, suppliers, shipments, warehouses, demand forecasts, and operational risks through an interactive Streamlit dashboard.

## Features
- Inventory Intelligence
- Supplier Scorecards
- Shipment Analytics
- Warehouse Utilization
- Demand Forecasting
- Reorder Recommendations
- Risk Dashboard

## Tech Stack
- MySQL
- SQL
- Python
- Streamlit
- Plotly
- Pandas

## Dataset
- 100 Suppliers
- 40 Warehouses
- 1,000 Products
- 20,000 Orders
- 50,000 Order Items
- 20,000 Shipments

Total: 90,000+ records

## Key Insights
- Identify stockout risks
- Monitor supplier performance
- Track delayed shipments
- Optimize inventory levels
- Improve demand forecasting

## How to Run

pip install -r requirements.txt

python -m streamlit run dashboard/app.py
